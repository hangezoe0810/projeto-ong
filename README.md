# ONG Solidária

Sobre o projeto

Esse projeto foi feito para uma ONG voltada para o resgate e cuidado de animais.
A ideia foi criar um site onde fosse possível conhecer a ONG, ver os projetos e fazer um cadastro.
O projeto também possui navegação em SPA, então as partes do site são carregadas sem precisar ficar trocando de página.
O que tem no projeto?
Parte para apresentar a ONG.
Projetos e iniciativas.
Formulário de cadastro, O formulário possui validações.

(Também foi utilizado localStorage para guardar informações.)

Foi utilizado HTML5 para fazer a estrutura. CSS3 para a parte visual e responsiva. JavaScript para as funções do projeto, navegação, eventos e armazenamento dos dados.

Também utilizei Git e GitHub para controlar as versões e guardar o projeto.

Pastas
A pasta css possui o arquivo style.css.
A pasta html possui os arquivos index.html, projetos.html e cadastro.html.
A pasta img possui as imagens e os ícones.
A pasta js possui os arquivos script.js, formulario.js e storage.js.

README.md com as informações do projeto.

Como executar
Primeiro é necessário clonar o projeto:
git clone https://github.com/hangezoe0810/projeto-ong.git

Depois entrar na pasta:
cd projeto-ong

Depois abrir a pasta no Visual Studio Code.
Para executar o projeto eu utilizei o Live Server para abrir o arquivo index.html no navegador.

Git e GitHub
Utilizei o Git para controlar as alterações feitas no projeto e o GitHub para deixar o projeto armazenado online.
Também utilizei as branches master, develop e feature para organizar o desenvolvimento.

JavaScript

O script.js ficou com as rotas e os templates.
O formulario.js ficou com as funções do formulário.
